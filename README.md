# Calculadora de Relevos

Una aplicación Android moderna diseñada para entrenadores y atletas de triatlón, que permite gestionar tiempos de relevos y optimizar la distribución de equipos.

## 🚀 Características
- **Introducción Manual**: Añade atletas y sus tiempos de forma rápida.
- **Cronómetro Integrado**: Toma tiempos en tiempo real con precisión de centésimas.
- **Algoritmo de Optimización**: Distribuye atletas en equipos (2 a 8) buscando minimizar la varianza del tiempo total (Greedy Algorithm).
- **Branding Personalizado**: Identidad visual del club Triatló.
- **Responsive**: Bloqueo vertical en móviles y soporte horizontal en tablets.

## 🛠️ Tecnologías
- **Jetpack Compose**: Interfaz de usuario declarativa.
- **Material 3**: Diseño moderno y accesible.
- **MVVM Architecture**: Separación clara de lógica y UI.
- **Kotlin Coroutines**: Gestión eficiente del cronómetro y tareas en segundo plano.
